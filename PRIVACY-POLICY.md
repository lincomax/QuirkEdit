# Privacy Policy

QuirkEdit is a free, open source text editor. It does not collect, store or share any personal data.

## No tracking

- No analytics, telemetry, crash reporting or advertising.
- No accounts, and nothing is sent to the developer.

## Network access

The app only connects to the internet when you ask it to:

- Git operations (clone, fetch, pull, push) to the remotes you set up.
- FTP and SFTP servers you add.

Those connections go straight from your device to the server you chose. Their own privacy policies apply.

## Permissions

- **Storage (all files access):** to open, edit and save files anywhere on your device.
- **Notifications and foreground service:** to show progress for long file operations such as copying or extracting.
- **Termux run command:** only used if you open a terminal through Termux.

## Your data

Settings, server details and git credentials are stored only on your device, in the app's private storage. Uninstalling the app removes them. Exported settings files are saved wherever you choose and never include your git password.

## Changes

Any changes to this policy will be posted in this repository.
